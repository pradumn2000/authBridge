# 🚀 **AuthBridge – BGV Verification & Document Authentication System**

This application is a **secure Background Verification (BGV) platform** designed for authentication and verification of user documents through DigiLocker and other verification sources.

It provides a complete **end-to-end verification lifecycle system** including candidate onboarding, document validation, verification workflows, reporting, and real-time tracking.

---

# 🔐 **Core Purpose**

The system enables organizations to:

* Verify candidate documents using **DigiLocker API**
* Manage complete verification workflows
* Provide real-time visibility to clients and admin teams
* Ensure secure document handling and authentication

---

# 🏗️ **System Architecture**

The platform is built using:

* **Backend:** PHP (Laravel)
* **Frontend:** HTML, CSS, JavaScript
* **Database:** MySQL
* **Architecture:** Modular + API-driven

# 🔄 **End-to-End Workflow**

The system follows a structured verification flow:

1. Client onboarding with pricing & check types
2. Case submission via client portal
3. QC validation (PVT role)
4. Case allocation based on check type
5. Parallel verification by specialized teams
6. Report generation (Process Specialist)
7. Final QC approval/rejection
8. Report delivery to client

👉 This workflow is fully aligned with the defined process document
